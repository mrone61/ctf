# LFI File Reader Challenge

A beginner-friendly challenge demonstrating Local File Inclusion (LFI) and path traversal vulnerabilities.

## Scenario

A web application allows users to read files from the server.

Improper validation allows attackers to access sensitive files.

Your objective is to retrieve the hidden flag.

---

## Requirements

```bash
pip install flask
```

---

## Setup

```bash
python app.py
```

---

## Access Challenge

```bash
http://127.0.0.1:5000
```

## Learning Objectives

- Local File Inclusion
- Path Traversal
- Sensitive file disclosure
- File handling vulnerabilities
