# JWT Authentication Bypass Challenge

A beginner-friendly challenge demonstrating JWT authentication misconfiguration.

## Scenario

A web application uses JWT tokens for authentication.

Due to improper token verification, attackers can forge admin tokens and bypass authorization controls.

---

## Requirements

```bash
pip install flask pyjwt
```

---

## Setup

```bash
python app.py
```
